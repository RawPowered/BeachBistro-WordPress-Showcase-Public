01 / HOMEPAGE

What the first screen has to do.

The homepage leads with the dock phone, an open or closed status, a plate over the scene, a table request, and the menu for the meal that is on right now.

Call bar

Key West, the fictional phone, and Open or Closed from the dock hours. The weekly line stays beside it.

Table request

Name, phone, email, party, service, and a date and time. It stays in preview until a recipient email is set.

Menu board

Plates, the griddle, and drinks. Breakfast, lunch, dinner, and all-day filters follow the kitchen clock. Brunch stays off in this mockup.

Sample notes

Short dock notes, marked as examples. No review counts and no claim of a working restaurant.

Edit the hero on the canvas.

The same eight-slot studio as the plumbing theme, retuned for this mockup. A scene sits behind a plate. Theme options still set type, the navy and tide palette, header, contact, hours, and map.

03 / THE DOCK

The tide band moves as you arrive.

The band tracks the scroll. The menu underneath follows the meal that is open. Reduced motion skips the decorative motion. Homepage speed is automatic: WebP art, layout CSS in the HTML, deferred scripts, and a saved guest copy. That cache turns off when another caching plugin should own the page.

Navy, tide, and sand

Navy, tide, sand, and cream. Food photos keep their own shape. They are not cropped to fill a frame.

Hours and meals

Open or closed from the dock clock, with holidays and special hours. Breakfast, lunch, and dinner filters follow that clock.

Lab check

Version 0.1.0 on WordPress 7.1.4. The test address stays internal.

04 / BUILD SHEET

Theme capabilities.

A WordPress theme with Hero Studio, theme options, the homepage menu, and the tide band. The menu, reservations, loyalty, OpenTable, and Popmenu pieces are optional plugins. None is required for the starter layout.

PHP

Templates, theme mods, and the contact handler.

WordPress

Core pages. Hero Studio is part of the theme.

CSS

Editorial layout and the dock palette. The homepage inlines that layout so text paints first.

JavaScript

Hero playback, the tide band, and the menu filters. Scripts wait until the homepage has been read.

Menu and WooCommerce

Dishes, a spreadsheet, kitchen windows, and a source switch. WooCommerce stays optional.

Reservations

A month and time picker, with dine-in, pickup, and takeout. OpenTable replaces the form only when a restaurant id is saved.
